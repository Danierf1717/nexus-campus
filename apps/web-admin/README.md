# Panel administrativo web

Panel para personal administrativo y administradores institucionales. Permitirá configurar servicios, atender solicitudes, gestionar usuarios según permisos y consultar indicadores autorizados.

La documentación inicial contempla HTML, CSS y JavaScript. La selección de un framework y herramientas de compilación queda pendiente de una decisión técnica antes de iniciar el frontend.

El panel consumirá la API REST del backend mediante HTTPS; nunca tendrá conexión directa a la base de datos.
