# Aplicación móvil — Flutter

Aplicación prevista para Android e iOS, desarrollada con Flutter y Dart.

## Organización propuesta de `lib/`

- `app/`: punto de entrada, navegación y configuración global.
- `core/`: tema visual, constantes, manejo de errores y utilidades.
- `data/`: cliente HTTP, DTOs, fuentes de datos y repositorios.
- `features/`: funcionalidades organizadas por módulo.
- `shared/`: componentes y widgets reutilizables.
